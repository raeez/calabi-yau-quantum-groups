## 0. Hostile Verdict

The surviving core is strong, but it is not yet safe as a free tuple.
The tuple

```tex
P^{BPS,strong}_{\sigma,S,o,T_{\mathrm{eq}}}(X)
 =
 (P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}}}(X),
  P^{BPS,\bullet}_{\sigma,S,o,T_{\mathrm{eq}}}(X),
  Dec)
```

must be integrated as an object of a typed fibered 2-category:

```tex
\mathsf{BPSGeom}^{or,mot}_{3CY}
  \longrightarrow
\mathsf{ChSect}_{3CY}.
```

The base `\mathsf{ChSect}_{3CY}` has objects

```tex
(C,\sigma,Q,S,T_{\mathrm{eq}})
```

and morphisms generated by exact CY equivalences, chamber inclusions,
ordered sector refinements, admissible wall paths, and equivariant
specializations preserving the support form.  The fibre over such a
base point is the category of completed oriented motivic Hall cosheaves
with vanishing-cycle coefficients, HN completion, motivic integration,
and realization tower.

The integrated theorem should therefore state:

```tex
\mathfrak I(X,\sigma,Q,S,o,T_{\mathrm{eq}},\mathsf{Mot})
  \in
\mathsf{Input}^{or,mot}_{3CY}
\quad\Longrightarrow\quad
P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}}}(X)
  \in
\mathsf{BPSGeom}^{or,mot}_{3CY}
```

with

```tex
Dec(P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}}}(X))
 =
P^{BPS,\bullet}_{\sigma,S,o,T_{\mathrm{eq}}}(X)
```

as a morphism of fibered objects, not as a post-facto extraction of a
list of invariants.

This is the first integration repair.  It is stronger than every free
tuple formulation because it fixes equivalence, refinement, functorial
transport, completion, and realization before any example is computed.

### C0. Finite-first principle

Attack.  Completion can hide invalid infinite products.  Several
statements use completed tensor products, inverse limits, and
quantum-dilogarithm products.  Without a finite-first axiom the same
symbol may mean a formal product, a topological inverse limit, or an
analytic convergence statement.

Heal.  Add the axiom:

```tex
\mathsf{F}_{N,R}
P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}}}(X)
```

is constructed first on every finite charge-height and central-charge
radius truncation, and every completed statement is the pro-object

```tex

 =
\varprojlim_{N,R}
\mathsf{F}_{N,R}P^{BPS,motloc}.
```

All products, realization functors, Hall pull-push maps, HN
factorizations, wall transports, pairings, and denominator products must
commute with the transition maps of this inverse system.

Integration recommendation.  Insert this as Axiom A-1 before support
property.  It strengthens A0--A8 and turns all compute tests into
finite witnesses of the actual object.

### C1. Orientation branch

Attack.  There is a conflict between "the orientation obstruction is
zero" and "a nonzero obstruction gives a gerbe-twisted theory".  If the
main thread integrates only the zero-obstruction branch, it loses Worker
02's stronger theorem.  If it integrates only the twisted branch, it
loses untwisted compact CY3 and Igusa normalizations.

Heal.  Define orientation as the disjoint union of two typed outputs:

```tex
\mathsf{OrOut}(M_C)
 =
\mathsf{Or}^{0}(M_C)
\sqcup
\mathsf{Or}^{tw}(M_C,c_o).
```

The untwisted branch has

```tex
[c_o]=0,\qquad O^{\otimes 2}=K_{M_C,s}.
```

The twisted branch has a fixed class

```tex
[c_o]\in H^2(M_C^{red},\mathbb Z/2)
```

and coefficients in the corresponding orientation gerbe.  Both branches
carry Thom--Sebastiani, Hall-fusion, triple-extension pentagon, and
quadratic-refinement data.

Integration recommendation.  Replace Axiom A1 by:

```tex
A1^{+}.  The critical atlas carries an orientation output
in \mathsf{OrOut}(M_C), and all subsequent Hall, integration,
realization, and automorphic constructions are taken in the
corresponding untwisted or gerbe-twisted coefficient category.
```

This is strictly stronger: the old zero-obstruction case is a fibre of
the new orientation-output theorem.

### C2. Primitive versus HN hull

BPS primitive data, but sector descent is true on the HN hull.  If the
main object indexes only primitive semistables, the cosheaf theorem is

Heal.  Build both layers into the object:

```tex

\subset
\mathcal M^{HN}_{\sigma,S}(\gamma),
```

with primitive BPS motives extracted from the KS logarithm of the HN
Hall element.  The cosheaf lives on `HN`; the support and BPS
multiplicities are extracted from the primitive/logarithmic layer.

Integration recommendation.  In every occurrence of
`\mathcal H_{\sigma,S}^{mot}`, specify whether it is built from
`M^{HN}` or from primitive semistables.  The merged convention should be:

```tex

 =
R\Gamma^{BM}(M^{HN}_{\sigma,S},\Phi^{vc}_o)^{\wedge},
```
