## Executive Theorem

The finite compute object is not an approximation to the chambered BPS
positive geometry.  It is the exact quotient

```tex
P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}},\leq N,\leq R}(X)
 =
P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}}}(X)/
I_{>N,>R}
```

where `I_{>N,>R}` is the closed Hall ideal generated by charges outside
the support-property bounded set

```tex
\Gamma_{\sigma,S,\leq N,\leq R}
 =
\{\gamma\in\Gamma^+_{\sigma,S,o}:
  h(\gamma)\leq N,\ |Z_\sigma(\gamma)|\leq R,\
  Z_\sigma(\gamma)\in S,\ Q(\gamma)\geq 0\}.
```

Every identity required by the infinite object is tested first in this
finite quotient.  Passing all finite quotients is the computational
form of the inverse-limit theorem:

```tex
P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}}}
 =
\varprojlim_{N,R}
P^{BPS,motloc}_{\sigma,S,o,T_{\mathrm{eq}},\leq N,\leq R}.
```

The stronger theorem target is therefore:

```tex
orientation cocycle
+ HN sector descent
+ motivic Hall associativity
+ KS joint holonomy
+ toric terminal collapse
+ conifold quantum pentagon
+ Igusa denominator normalization
```

all verified by exact finite certificates.  The engine does not replace
proofs.  It makes the failure modes finite, typed, reproducible, and
strong enough to falsify incorrect signs, completions, orderings, and
normalizations.

`FiniteChargeSet` is finite by construction.  The support property is

listed charge; failure means the truncation was not honestly cut from
the stability datum.

The quotient product is:

```tex
x_\alpha *_H x_\beta
 =
\mathbb L^{-\langle\alpha,\beta\rangle/2}
\epsilon_o(\alpha,\beta)x_{\alpha+\beta}
```

in Hall convention and:

```tex
x_\alpha *_T x_\beta

\mathbb L^{\langle\alpha,\beta\rangle/2}
\epsilon_o(\alpha,\beta)x_{\alpha+\beta}
```

in integrated quantum-torus convention.  The engine must carry the
convention tag and refuse to multiply objects with different tags.

## Witness 1: Orientation Cocycle

The finite orientation oracle works on the Cech nerve of the chosen
critical atlas.  Store signs additively in `F_2`:

```tex
\theta_{ij}\in\mathbb F_2,\qquad
c_{ijk}=\theta_{ij}+\theta_{jk}+\theta_{ki}.
```

The cocycle condition is:

```tex
(\delta c)_{ijkl}
=c_{jkl}+c_{ikl}+c_{ijl}+c_{ijk}=0
\quad\text{in }\mathbb F_2.
```

The orientation witness returns:

```python
OrientationCertificate(
    cech_delta_zero: bool,
    obstruction_class: dict[tuple[int, int, int], int],
    quadratic_refinement_ok: bool,
    thom_sebastiani_ok: bool,
)
```

The quadratic-refinement check is:

```tex
q_o(\alpha+\beta)
 =
(-1)^{\langle\alpha,\beta\rangle}q_o(\alpha)q_o(\beta).
```

The Thom--Sebastiani check is the multiplicativity of the orientation
line over all retained pairs:

```tex
O_{\alpha+\beta}
 =
O_\alpha\boxtimes O_\beta\otimes
\mathbb L^{-\langle\alpha,\beta\rangle/2}
```

inside the finite quotient.  A nonzero `Cech^2(F_2)` class is not erased:
the certificate is then marked as gerbe-twisted, and the Hall product is
formed in the twisted coefficient target.  This is a stronger object
than silently forcing a sign choice.

## Witness 2: Hall Associativity

For all triples retained by the charge quotient:

```tex
\alpha,\beta,\gamma,\alpha+\beta,\beta+\gamma,\alpha+\beta+\gamma
\in\Gamma_{\leq N,\leq R},
```

the engine checks:

```tex
(x_\alpha *_H x_\beta)*_H x_\gamma
 =
x_\alpha *_H (x_\beta *_H x_\gamma).
```

This reduces to two finite equalities:

```tex
\langle\alpha,\beta\rangle
+\langle\alpha+\beta,\gamma\rangle
=
\langle\beta,\gamma\rangle
+\langle\alpha,\beta+\gamma\rangle
```

and

```tex
\epsilon_o(\alpha,\beta)
\epsilon_o(\alpha+\beta,\gamma)
=
\epsilon_o(\beta,\gamma)
\epsilon_o(\alpha,\beta+\gamma).
```

The first is bilinearity.  The second is the orientation `2`-cocycle
condition.  The executable witness must enumerate all triples in the
finite charge set, not merely sample them.

## Witness 3: HN Sector Descent

Let

```tex
S=S_1\star\cdots\star S_r
```

be an ordered strict-sector cover.  The finite HN word set is:

```tex
\mathrm{HN}_{\leq N,\leq R}(S)
 =
\{(\gamma_1,\ldots,\gamma_k):
  \gamma_i\in\Gamma^{ss}_{S_j}
  \text{ for decreasing sector order, }
  \sum_i\gamma_i\in\Gamma_{\leq N,\leq R}\}.
```

The descent witness compares two exact finite sums:

```tex
\sum_{\gamma\in\Gamma_{\leq N,\leq R}(S)}
[\mathcal M^{HN}_{S}(\gamma)]x_\gamma
```

and

```tex
\prod_{j=1}^r
\left(
\sum_{\gamma\in\Gamma^{ss}_{S_j,\leq N,\leq R}}
[\mathcal M^{ss}_{S_j}(\gamma)]x_\gamma
\right)
```

with the product taken in descending phase order.  The witness is not a
commutative generating-function comparison; it uses the Hall/quantum
torus multiplication and therefore sees orientation signs and Euler-form
twists.

For the conifold `A_2` chart this specializes to the pentagon:

```tex
E(X)E(Y)=E(Y)E(XY)E(X).
```

## Witness 4: KS Loop Holonomy


The KS factor is represented in the completed finite quantum torus:

```tex

 =
\operatorname{PExp}
\left(
\Omega_\gamma x_\gamma
\right)
```

with compact quantum dilogarithm convention for the conifold and
motivic plethystic convention for the motivic object.

For a codimension-two joint, the loop holonomy certificate is:

```tex
\prod_{\ell\in\partial D}^{\circlearrowright}
\mathbb E_{\gamma_\ell}^{\Omega_{\gamma_\ell}}
```

## Failure Modes the Engine Must Detect

1. **Orientation collapse.**  Replacing a nonzero `Cech^2(F_2)` class by
   a chosen sign without marking the coefficient system as twisted.

2. **Convention mixing.**  Multiplying Hall-convention and
   integrated-quantum-torus-convention elements in one product.

3. **Commutative sector descent.**  Comparing ordinary generating
   functions instead of ordered Hall products.

4. **Pair-commutator inflation.**  Treating leading BCH scattering
   multiplicities for K3 x E as the full `phi_{0,1}` BPS multiplicities.

5. **Igusa normalization loss.**  Confusing `Delta_5`,
   `64^{-1}Delta_5`, `Delta_5(2Z)/64`, and `Phi_10=Delta_5^2`.

6. **Positive half versus double.**  Passing `Y^+` tests and reporting a
   Drinfeld double without Cartan, negative half, pairing, coproduct, and
   radical quotient certificates.

7. **Toric overreach.**  Passing `C^3` or conifold and claiming a compact
   non-toric CY3 Hall construction without the oriented critical atlas
   and HN support data.

Each failure produces a finite counterexample: a charge, triple of
charges, sector cover, wall loop, or Fourier coefficient.
