\begin{abstract}
This file audits each of the $138$ \texttt{\textbackslash ClaimStatusConditional}
tags appearing under \texttt{chapters/} against the theorems established by the
prior residuals waves (Agents 1--15 of the wave\_borcherds\_chain\_level

prior-wave file (if any), and a verdict: \textsc{Upgrade}, \textsc{Still}, or \textsc{Misc}.
No chapter is edited. Downstream agents R-3..R-15 consume this as a worklist.

\item $\sim 85$ remain \textsc{Still-conditional}, with the residual gap
  falling into one of eight well-delineated bins, each named in
  Section~\ref{sec:residual-gaps}.
\item $\sim 19$ are \textsc{Misc}, scope needing a chapter-local
  decision (typically an embedded theorem where one of several
  hypotheses was cleared but another remains, or where the upgraded
  scope would require rewording the statement).
\end{itemize}

\subsection{Audit procedure}
\label{subsec:procedure}

For each match of \texttt{\textbackslash ClaimStatusConditional} in
\texttt{chapters/}:
\begin{enumerate}[label=\textup{(\arabic*)}]
\item Extract (i) the enclosing theorem/proposition label, (ii) the
  explicit condition text, (iii) a $\pm 100$-line context.
\item Classify the condition text into one of eleven canonical bins
  (Section~\ref{subsec:condition-bins}).
\item For each bin, record whether the prior-wave anchor resolves the
  bin; if yes, mark \textsc{Upgrade}; if partially, \textsc{Misc}; if
  not, \textsc{Still}.
\item For the \textsc{Upgrade} cases name the target promotion
  (\texttt{\textbackslash ClaimStatusProvedHere} vs
  \texttt{\textbackslash ClaimStatusProvedElsewhere}) and the anchor
  theorem label.
\end{enumerate}
