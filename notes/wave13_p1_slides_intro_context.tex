\subsection*{Stated motivation --- the diagonal-divisor problem
(lines 29--44)}

The motivating question, stated verbatim on slide 2:

\emph{For congruence subgroups $\Gamma_t(N)<\Gamma_t$ of Hecke type
(paramodular groups of genus 2), which Siegel modular forms (with
character/multiplier system) vanish exactly along $\Gamma_t(N)$-translates
of the diagonal $\{\mathrm{diag}(a,b)\mid a,b\in\mathbb{H}_1\}\subset
\mathbb{H}_2$ precisely to order~1?}

This is the classification problem whose solution (next slide, line 47)
isolates \textbf{exactly eight} diagonal-divisor forms. The eight-form
count is the same count that reappears in the memory index as the
correspondence $\{\text{8 Gritsenko--Cl\'ery forms}\}
\leftrightarrow \{\text{DT zeta roots}\}
\leftrightarrow \{\text{twined elliptic genera}\}$, i.e.\ Conjecture 1
of the paper.
