\chapter{Test Suite Documentation}
\label{app:tests}

This appendix documents the computational test suite that verifies the
mathematical claims of Volume~III.

\section{Overview}
\label{sec:test-overview}

The test suite comprises 30,613 tests organized across 369 test files in
\texttt{compute/tests/}.  Every formal claim tagged
\ClaimStatusProvedHere{} or \ClaimStatusConditional{} that admits
numerical verification has at least one corresponding test.  Tests are
run via \texttt{make test} (equivalently
\texttt{python3 -m pytest compute/tests/ -q}).

\section{Organization}
\label{sec:test-organization}

\begin{itemize}[nosep]
\item \textbf{Engine tests} (\texttt{compute/tests/test\_<engine>.py}):
  Each of the 334 compute engines in \texttt{compute/lib/} has a
  corresponding test file (329 engines have dedicated tests; 5 are
  tested via related engine test files).

\item \textbf{Integration tests}: Parametrized tests in
  \texttt{conftest.py} expand single test functions across multiple CY
  geometries (e.g., $\C^3$, conifold, local $\bP^2$, quintic, K3,
  K3$\times E$), contributing to the 30,613 total.

\item \textbf{Verification scripts} (\texttt{compute/scripts/}):
  Three standalone scripts for high-precision cross-validation:
  \texttt{cross\_validate\_phi01.py},
  \texttt{verify\_igusa\_high\_precision.py},
  \texttt{verify\_shadow\_tower\_clean.py}.

\item \textbf{Audit reports} (\texttt{compute/audit/}): Seven audit
  reports documenting cross-consistency checks and status sweeps.
\end{itemize}

\section{Multi-path verification}
\label{sec:test-multipath}

Key results are verified through multiple independent computational paths:

\begin{itemize}[nosep]
\item \textbf{$\C^3$ / $\cW_{1+\infty}$}: Five independent constructions
  (cyclic $\Ainf$, Lie conformal, factorization envelope, CoHA,
  $\hCS$ stage-1 shadow)
  verified to agree: \texttt{c3\_grand\_verification} (104 tests).

\item \textbf{K3 Yangian}: Three routes (Mukai lattice, BFN Coulomb
  branch, Bridgeland stability) cross-checked:
  \texttt{k3\_yangian\_adversarial} (45 tests).

\item \textbf{Kummer route}: Steps 1--4 verified via direct computation
  and independent excision argument:
  \texttt{kummer\_excision\_verification} (71 tests).

\item \textbf{Bar-hocolim commutation}: Chain-level and cohomological
  verification across all standard CY3 families:
  \texttt{bar\_hocolim\_chain\_level} (145 tests).

\item \textbf{Borcherds denominator}: Direct Fourier expansion vs
  bar Euler product identification:
  \texttt{borcherds\_denominator\_phi10\_engine} (62 tests).
\end{itemize}

\section{Running the tests}
\label{sec:test-running}

\begin{verbatim}
cd ~/calabi-yau-quantum-groups
make test                            # Full suite (~3 min)
python3 -m pytest compute/tests/ -q  # Equivalent
python3 -m pytest compute/tests/test_<engine>.py -v  # Single engine
python3 -m pytest -k "k3_yangian" -v # Pattern match
python3 -m pytest -m "not slow" -q   # Exclude slow tests
\end{verbatim}
